5 — Structural concept

  • Frame-first: closed transverse octagon ring webs on the inner mold (8 edges per station), with athwart gaps at corridors/crossing/stairs and vertical door band at shell.
  • Ring web solids: 0; shell corner brackets tie web to plate.
  • Deck longitudinals (keel + corridor girders) and transverse deck beams at each frame station.
  • Frame solids: 184; stringer bays: 160.
  • Lock web thickness: 0.15 m.
  • Station set: ST0, ST1, ST2, ST3, MB1, MB2, AFT.
