Manufacturer notes

  1. Build the outer shell by lofting octagon rings ST0→ST1→ST2→ST3→MB1→MB2→AFT with the listed quads.
  2. Cut the aft door opening using DOOR.* rectangle on the AFT plane; keep ≥0.50 m clear around the C40 pack (PACK.*).
  3. Origo is intentionally outside the ship — do not place structure at (0,0,0).
  4. Keep PAD synchronized if you change the GA envelope; regenerate this file from generate-mesh.mjs.
